## 3. 海報的自動生成 skill

產出:`docs/skills/packgo-poster/`(SKILL.md + 模板 + 渲染器 + install.sh)

做這個的理由不只是省事。鐵閘寫「供應商成本/圖不上客面」,但目前發廣告的
實務是轉發供應商海報 — 那上面是供應商品牌,有時印著成本或同業價,
版權也不在我們手上。這個 skill 就是用來取代「轉發供應商海報」這個動作。

能力:

- 一份 HTML 出五種尺寸:朋友圈/LINE 1080×1350、IG 方形 1080×1080、
  限時動態 1080×1920、A4 列印 2480×3508(300dpi)、A4 PDF(實體 8.27×11.69 吋)
- 品牌色與報價單/收據同一組(深藍 #1B2A4A + 金 #C9A96E)
- 紅線寫進 SKILL.md:成本不上、供應商圖不上、圓角、假急迫禁用、價格須核對

技術上踩到並修掉的坑,記著免得重犯:

- headless Chrome 的 `--window-size` 給的是外框尺寸,實際 viewport 少 87px,
  截圖卻照外框輸出 → 版面底部被切、圖檔下緣留白。改走 CDP
  (`Emulation.setDeviceMetricsOverride` + `Page.captureScreenshot` 帶 clip),
  尺寸逐像素可控,並在出圖後驗尺寸,不符就 HALT。不需裝任何 npm 套件。
- hero 用絕對定位在矮版型(方形)會和 logo 疊字 → 改 flex 排版。
- hero 可壓縮會切掉主標 → 改 `flex: 1 0 auto`(可長不可縮),
  塞不下時交給 autoFit 整體縮排,縮到 0.82 還塞不下就在圖上插紅色警示條並 HALT。
  寧可醜到不可能誤發,也不要靜靜切掉價格或電話。

驗證(親跑):四種 PNG 尺寸 + A4 PDF 全部產出,尺寸逐項核對相符;
方形版觸發 autoFit 0.96 並正常收斂;install.sh 裝到獨立目錄後重跑渲染通過;
四張 PNG 目視確認無溢出、無疊字、頁尾聯絡資訊完整。
